## 🛠️ Local Development

To run the website locally:

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser or use the Live Server extension.
4. Edit the HTML, CSS and JavaScript files as needed.

The website does not require a database or server-side framework for its core functionality.

## 🌍 Deployment

The website is designed for deployment through **GitHub Pages**.

Once GitHub Pages is enabled, the live website will be available at:

`https://YOUR-USERNAME.github.io/triple-v-media-coming-soon/`

Replace `YOUR-USERNAME` with the repository owner's GitHub username.
