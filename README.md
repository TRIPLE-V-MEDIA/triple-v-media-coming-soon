# Triple V Media — Coming Soon

Open `index.html` in a browser, or use the VS Code Live Server extension.

## Customize
- **Launch date:** `LAUNCH_DATE` in `script.js`. `+02:00` is South African Standard Time.
- **Development progress:** `DEVELOPMENT_PROGRESS` in `script.js` (currently 75% illustrative, not actual tracked progress).
- **Email:** Set `CONTACT_EMAIL` in `script.js` to an address you own. The form then opens an email draft; it **does not save subscribers or send automatic launch emails**. For a real mailing list, connect a provider such as Formspree, Brevo, Mailchimp, or a backend with consent and privacy handling.
- **Social links:** Replace the generic platform homepage URLs in `index.html` with Triple V Media's actual accounts.
- **Branding:** The VVV mark is typographic placeholder artwork. Replace it with your official logo when ready.
- **Colours:** Change `--red`, `--bg`, and other variables at the top of `styles.css`.

## Deploy
Upload the three files to your hosting provider (e.g., Netlify, GitHub Pages, cPanel public_html). No build step needed. Internet access is used only to load Google Fonts; fallback fonts are provided.
